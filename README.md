# Showroom 3D · Catálogo Interactivo para Tiendas de Ropa

Experiencia de exhibición virtual e-commerce en 3D inspirada en diseño minimalista estilo Apple / iMac.

Permite a las marcas presentar sus colecciones en un perchero interactivo con física de telas, rotación 360° frente/espalda y cotización directa por WhatsApp.

## Características

- **Perchero 3D con Físicas**: Deslizamiento fluido con inercia y balanceo de prendas.
- **Doble Modo de Exhibición**:
  - `Studio Titanium`: Colección contemporánea unisex / streetwear.
  - `Atelier Blush`: Colección femenina con paleta de tonos cálidos y rosados.
- **Fichas Técnicas Modales**: Inspección de prendas, gramajes (GSM), telas y calce.
- **Cierre Directo por WhatsApp**: Contacto prellenado sin fricción de carritos abandonados.
- **Diseño Ultra Rápido**: Desarrollado con Vite, React 19, TypeScript y Tailwind CSS con tokens de shadcn/ui.

## Instalación y Desarrollo Local

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Generar build de producción
npm run build
```

## Despliegue en Vercel

Este proyecto está optimizado para importarse y desplegarse en [Vercel](https://vercel.com/) con un solo clic desde GitHub.
